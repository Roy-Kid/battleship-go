Core concept: interfaces

An interface specifies how one part of a program asks another part to do something: the available operations, required inputs and promised results.

The game is our worked example of this programming concept.

Begin with this definition. Ask the learner to restate it before tracing the example. Other syntax is review or teacher-supplied support.

Worked example: interfaces

# In the integrated game:
connection.submit('attack', x=3, y=4)
# The request asks for an attack. It does not promise a hit.

Three requests to trace

connection.submit('ready', fleet=[dict(s) for s in fleet])
connection.submit('attack', x=x, y=y)
connection.submit('rematch')

submit adds the action field. Connection also handles join and state polling.

20–25 minutes: locate these calls in main.py. Students record data fields; sockets and threads remain supplied.

Ready locks the fleet

  1. Use Random fleet, or place three ships yourself.
  2. Press Ready in one client and check its locked state.
  3. Ready the other client to start battle.
  4. Find whose turn it is, then fire once.

Only the server can advance the shared match phase.

45–55 minutes: select 1/2/3, R rotates; click left to place and right to fire on your turn. Ready fleets cannot be edited.

A rematch needs both votes

StateAfter the action
Finished + one voteStill finished, votes = 1
Same player votes againStill one distinct vote
Other player votesNew placement phase, next round
New roundShots/fleets reset; wins persist

The opening player alternates each round.

95–100 minutes: Match.votes is a set. Verify first-player rotation after both players ready their next fleets.

Acceptance and disconnect checks

  1. Ready players cannot reposition ships.
  2. Out-of-turn and repeated attacks change no records.
  3. A snapshot never reveals the enemy fleet.
  4. One vote waits; two votes reset the round.
  5. Closing one client shows departure on the other.
100–110 minutes: after disconnect, close both clients before reconnecting. The one-room server clears when both have left.

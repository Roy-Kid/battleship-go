Functions

Name a useful operation, give it inputs, and use its result.

Define → Predict → Run → Explain · 120 minutes

Introduce today’s concept first. Demonstrate the game feature as its application. Other syntax is review or supplied support.

Definition: a named operation

A function is a named block of instructions that can receive arguments and return a result.

def report_position(x, y):
    print("Ship position:", x, y)

report_position(200, 180)
0–15 minutes: reuse the Day 1 optional report_position example. def prepares the operation; the call runs it.

A call can return a result

from board import cells
ship = {'name': 'Scout', 'x': 2, 'y': 3,
        'vertical': False}
occupied = cells(ship)
print(occupied)  # [(2, 3), (3, 3)]

Here x/y identify board cells, not Day 2 pixels.

20–25 minutes: cells already exists in board.py. Use its returned list directly.

Definition and call are different

def report_position(x, y):
    print("Ship position:", x, y)

# No output until this call:
report_position(500, 300)

Printing is an effect. Returning hands a value back to the caller.

35–40 minutes: report_position prints and implicitly returns None. cells returns a value. Do not confuse the two.

Loops

Describe repeated work once, then use it to draw a board.

Definition: repetition

A loop repeats a block of instructions. A for loop visits each item in an iterable, such as range(11).

for i in range(3):
    print(i)

One pass through the block is an iteration.

0–15 minutes: recap Day 2 collections. The for loop visits a sequence of values. Predict 0, 1, 2 before running.

A loop has three parts

PartExampleRole
Iteration variableiReceives the current value
Iterablerange(3)Supplies values 0, 1, 2
Indented bodyprint(i)Runs once per value
15–20 minutes: the colon starts the block. Indentation controls which statements repeat.

range stops before its endpoint

for i in range(11):
    print(i)  # 0 through 10
How many iterations?

Eleven. range(10) would give ten: 0 through 9.

20–25 minutes: ask for the first and last values separately from the count.

Ten cells need eleven boundaries

A row starts with a left boundary, then needs one more boundary after each of ten cells.

CELL = 40
for i in range(11):
    x = LEFT + i * CELL

x takes eleven evenly spaced values.

25–35 minutes: draw the first three boundaries on paper. The repeated calculation produces each position.

Apply the loop to the board

for i in range(11):
    pygame.draw.line(screen, "white",
                     (LEFT+i*CELL, TOP),
                     (LEFT+i*CELL, TOP+400))

The drawing API is supplied. Your job is to explain what changes on each iteration.

35–45 minutes: use the vertical-line pattern in main.py. Then apply the same i to horizontal boundaries.

Core concept: state machines

A state machine represents a program as named states and transitions. An event changes state only when its transition rule allows it.

The game is our worked example of this programming concept.

Begin with this definition. Ask the learner to restate it before tracing the example. Other syntax is review or teacher-supplied support.

Worked example: state machines

phase = 'battle'
sunk = 3
if phase == 'battle' and sunk == 3:
    phase = 'finished'
print(phase)  # finished

Name the states before and after victory, the event that triggers the transition, and an action forbidden after it.

Predict first, then run or trace the example. Ask the student to identify the input, operation and result. Use the daily README for the runnable context.

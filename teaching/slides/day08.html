Core concept: serialization

Serialization converts structured data into a representation that can be stored or transmitted. Deserialization reconstructs the data from that representation.

The game is our worked example of this programming concept.

Begin with this definition. Ask the learner to restate it before tracing the example. Other syntax is review or teacher-supplied support.

Worked example: serialization

import json
message = {'name': 'Alice', 'text': 'Ahoy!'}
wire_text = json.dumps(message)
restored = json.loads(wire_text)
print(restored == message)  # True

Distinguish a Python dictionary, JSON text and encoded bytes. Which step reconstructs the dictionary?

Predict first, then run or trace the example. Ask the student to identify the input, operation and result. Use the daily README for the runnable context.

Serialization defines the representation; encoding turns its text into bytes.

Use this type trace before network commands. A dictionary is not a byte stream, and printing it is not the complete transport protocol.

Predict a serialization round trip

import json
message = {'name': 'Alice', 'text': 'Ahoy, Båt! *'}
payload = json.dumps(message, ensure_ascii=False)
wire = payload.encode('utf-8')
restored = json.loads(wire.decode('utf-8'))
print(type(payload).__name__, type(wire).__name__)
print(restored == message)

str bytes
True

One newline ends one message

{"name": "Alice", "text": "x=3, y=4"}

The sender appends a newline. The reader waits for one complete line.

A TCP read may contain part of a message or several messages.

50–55 minutes: explain framing at the concept level. Students do not implement it. A typed newline within a JSON string is escaped by the encoder.

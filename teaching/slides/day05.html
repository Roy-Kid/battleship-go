Battleship Lab · Day 5 · One core concept

Conditional branching

Choose what the program does by asking a true-or-false question.

Define → Predict → Run → Explain · 120 minutes

Introduce today’s concept first. Demonstrate the game feature as its application. Other syntax is review or supplied support.

Definition: choose a branch

A conditional chooses which block of instructions runs according to whether a condition is true or false.

kind = 'miss'
if kind == 'miss':
    print('Try another cell')
else:
    print('Ship hit!')
0–15 minutes: conditionals appeared in supplied scaffolds earlier. Today students explicitly predict and write branches.

A condition produces a boolean

ExpressionMeaningExample result
kind == 'miss'Equal toTrue for miss
phase == 'battle'Current phase permits attacksFalse during placement
0 <= col < 10Coordinate is within boundsTrue for col=3

= assigns a value. == asks about equality.

15–20 minutes: use concrete values and ask for True or False before discussing the action.

Only the selected branch runs

kind = 'hit'
if kind == 'miss':
    message = 'MISS'
elif kind == 'sunk':
    message = 'SUNK'
else:
    message = 'HIT'
print(message)

if tests first; elif tests only if needed; else handles the remaining case.

20–30 minutes: output is HIT. Trace miss, hit and sunk one at a time.

The rules return data; the UI chooses feedback

result = fire(enemy, shots, col, row)
kind = result['kind']

fire already decides miss, hit or sunk. Your branch chooses what to show.

Call the existing rule function instead of implementing a second hit detector.

30–35 minutes: the concept application is feedback and action gating; fleet lookup and shot validation remain supplied.

Guard an action with a condition

if (phase == 'battle'
        and RIGHT <= mx < RIGHT+360
        and TOP <= my < TOP+360):
    col, row = (mx-RIGHT)//CELL, (my-TOP)//CELL
    result = fire(enemy, shots, col, row)

Both coordinate bounds must hold. A click outside the board is not a valid target.

35–40 minutes: trace the compound condition in the event handler. All three conditions must be true. The supplied code converts the coordinates and calls fire.

Compare the explicit branches in main.py after your attempt.

Acceptance checks

Core concept: data and operations

Data are values a program stores and uses. An operation reads, combines or changes values to produce a result.

The game is our worked example of this programming concept.

Begin with this definition. Ask the learner to restate it before tracing the example. Other syntax is review or teacher-supplied support.

Worked example: data and operations

x = 200             # Data: an integer stored with a name
x = x + 40          # Operation: addition, then assignment
print(x)            # Operation: display the result, 240

Identify the data, operation and result in x = x + 40. Predict before running.

Predict first, then run or trace the example. Ask the student to identify the input, operation and result. Use the daily README for the runnable context.

x = x + 40: calculate, then assign

x = 200
x = x + 40

  2. Calculate 200 + 40: 240.
  3. Store 240 back in x.

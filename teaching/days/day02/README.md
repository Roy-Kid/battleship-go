# 第2天：用键盘控制舰船

本课2小时。知识：条件、事件、变量更新、布尔值。

## 运行

在已激活的Python 3.13环境中进入本目录：

```bash
python main.py
```

`starter.py` 是课堂起点，`main.py` 是参考完成版。从上一天的可运行程序开始，新增本课功能。

## 学生任务

从第1天画面出发，读取方向键；按R改变朝向；根据图片大小限制窗口边界。

## 老师提供

Pygame 的事件与按键API由老师演示。旋转从原图生成，避免重复缩放。

## 挑战与验收

先说预测，运行验证，再解释原因。每次保存一个可运行版本。本目录包含独立素材，可单独复制；无需访问相邻天的目录。
